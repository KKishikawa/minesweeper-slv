# ADR 0005: 不確実な盤面は手動確認までsolverへ渡さない

Status: accepted

Decision date: 2026-08-16
Recorded: 2026-09-11（歴史資料から遡及記録）

## Context

認識結果には低信頼度セル、指定寸法との不一致、局所または全体の盤面矛盾が含まれる可能性があります。これらを確定した盤面としてsolverへ渡すと、正しそうに見える誤った提案を利用者へ示す危険があります。

盤面の観測値とsolver提案は別の状態であり、solverの結果が入力盤面を上書きしない境界も必要です。

## Considered Options

- 不確実なセルを推測で補ってsolverを続行する。
- 不確実または矛盾する盤面では停止し、利用者の確認または修正を待つ。

## Decision

不確実なセルや、入力時の検証で判明する局所矛盾・総地雷数との矛盾がある場合、solverによる提案解析を開始しません。事前検証を通過した後にsolverが全体矛盾を判定した場合も、確定または推測の提案を表示しません。利用者の手動確認または修正後に盤面revisionを更新し、認識を再実行せず、検証とsolverだけを再実行します。認識の不確実性、盤面矛盾、推測が必要な正常状態、探索上限到達は区別します。

## Consequences

- 認識結果が未確認のままsolverの確定提案へ流れません。
- 手動修正は画像認識の有無に依存しない安全な入力経路になります。
- revisionより古い非同期結果を破棄する必要があります。
- 認識失敗時にも直前の有効な盤面を保持できます。
