# 入力方式切替とフォーカス復帰（Issue #23）

2026-10-10に承認した方式。対象は[#23](https://github.com/KKishikawa/minesweeper-slv/issues/23)。以前はセルへのフォーカス復帰クリックでパレット値が必ず入力され、観測値が失われた。

## 採用した方式

- 起動時に `matchMedia('(pointer: coarse)')` が一致する場合はクリック・タップ中心、それ以外はキーボード中心とする。端末の種類を完全に判定する必要はないという合意に基づく。
- 入力方式のラジオボタンでいつでも手動切替できる。起動後にデバイス特性が変わっても自動で切り替えない。盤面の更新・再作成・リセットでも方式を維持する。再読み込み時は初期判定を行う。保存は追加しない。
- キーボード中心ではクリックはセルの選択とフォーカス移動のみ。パレットは隠し、入力キーを説明する。
- クリック・タップ中心ではパレットの全値を入力できる。説明はタップ手順と方式の切替案内にする。既存の入力キーも引き続き利用できる。
- キーの受付範囲はセルのまま。設定欄やカード全体には広げない。Tab・Enterはnative動作を維持し、セルのEnterによるボタンactivationも現在の方式に従う。

フォーカス専用の修飾キー操作では通常クリックで復帰したい目的を満たしにくい。カード全体でのキー受付は設定・ボタン・IMEとの干渉範囲が増える。今回は、操作方式を明示する切替を採用した。
